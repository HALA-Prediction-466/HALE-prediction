## Methodology

1. **Preprocessing**
   Linear interpolation per country, backward fill for year 2000, mean imputation for remaining missing values.

2. **Feature Engineering**
   Cyclical encoding of year and one-hot encoding of categorical variables.

3. **Target Variable**
   HALE_60 (kept in original units: years). HALE_Birth used as an input feature.

4. **Temporal Split**
   Training: 2000–2014
   Testing: 2015–2019

5. **Scaling**
   StandardScaler (rates) and MinMaxScaler (percentages), fitted on training data only.

6. **Models**
   Linear Regression, Random Forest, Gradient Boosting.

7. **Evaluation Metrics**
   R², MAE (years), RMSE (years).

## Results

| Model             | Test R² | Test MAE (years) | Test RMSE (years) |
| ----------------- | ------- | ---------------- | ----------------- |
| Linear Regression | 0.9637  | 0.7289           | 1.2220            |
| Random Forest     | 0.9543  | 1.0140           | 1.3716            |
| Gradient Boosting | 0.9799  | 0.6126           | 0.9097            |

Gradient Boosting achieved the best performance.
